One line roasting the AI agent our own team built, judged head-to-head until one roast stands. The entry: "My agent calls a 34-second sale '2 seconds' and a guaranteed 3x win 'a learning experience'." The sting is earned, not generic: our agent once quoted a 2-second sale that took 34 seconds in practice, and sold a structurally guaranteed 3x winner at half price.

## Run it

```sh
node main.ts
```

`main.ts` writes the roast to `ENTRY_OUTPUT` or `/output/entry.txt` — exactly one line, 92 characters, no trailing newline.
